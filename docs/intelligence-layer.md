# PRISM Intelligence Layer

PRISM includes a five-component Intelligence Layer that operates before and alongside AI capability execution to improve output quality, reduce costs, and enable intelligent routing.

---

## 1. Prompt Tutor

**File:** `x402-demo-server/services/promptTutor.ts`  
**Route:** `POST /api/prompt-tutor`

Evaluates the quality of user-supplied prompts and returns actionable improvement tips before execution.

### What it does:
- Scores prompt quality across dimensions: clarity, context, specificity, and completeness
- Returns structured feedback: what is strong, what is missing, and exact recommendations
- Helps users write better prompts without requiring them to understand AI prompting mechanics

### Status: **Implemented — Real**

---

## 2. Data Map

**File:** `x402-demo-server/services/dataMap.ts`  
**Route:** `POST /api/data-map`

Builds a structured context graph from task inputs and attached files to precisely map the task against available PRISM capabilities.

### What it does:
- Parses task descriptions and input types
- Identifies entities, document types, and required capability categories
- Produces a structured mapping used by the AI Router for endpoint selection

### Status: **Implemented — Real**

---

## 3. Semantic Cache

**File:** `x402-demo-server/services/semanticCache.ts`  
**Route:** `POST /api/semantic-cache`  
**Model:** `SemanticCache` (MongoDB)

Avoids redundant AI execution by detecting semantically similar requests and returning cached results.

### What it does:
- Hashes request content against a MongoDB-backed cache
- Performs semantic similarity comparison on previous requests
- Returns cached results for substantially identical workloads — reducing cost and latency
- Cache entries stored in `models/SemanticCache.ts`

### Status: **Implemented — Real**

---

## 4. Prompt Optimizer

**File:** `x402-demo-server/services/promptOptimizer.ts`  
**Route:** `POST /api/prompt-optimizer`  
**Model:** `PromptOptimization` (MongoDB)

Rewrites raw user task descriptions into structured, system-optimized prompts before dispatching to AI models.

### What it does:
- Decomposes ambiguous natural language into structured intent
- Injects relevant context from the Data Map
- Formats prompts for the target model tier (fast vs. accurate)
- Logs optimizations to MongoDB for analytics and learning

### Status: **Implemented — Real**

---

## 5. AI Router

**Files:** `x402-demo-server/handlers/classify-task.ts`, `x402-demo-server/handlers/select-endpoint.ts`

Selects the appropriate AI capability endpoint and model tier based on task type, quality requirements, and cost parameters.

### What it does:
- Classifies user intent into one of PRISM's task categories (code review, resume screening, contract analysis, etc.)
- Evaluates competing endpoint options within each category (fast vs. accurate)
- Applies scoring based on: price, confidence estimate, and endpoint reputation
- Returns the winning endpoint selection with justification

### Status: **Implemented — Real**

## Intelligence Layer Flow

```
User Task Description
        ↓
   Prompt Tutor      ← Evaluates prompt quality
        ↓
    Data Map         ← Builds structured context
        ↓
Semantic Cache       ← Returns cached result if match found
        ↓  (cache miss)
Prompt Optimizer     ← Rewrites prompt for execution
        ↓
   AI Router         ← Selects capability + model tier
        ↓
  x402 Payment       ← Enforces per-use access
        ↓
Capability Handler   ← Executes AI workload
        ↓
Structured Result
```

---

## Intelligence Layer and Cost Reduction

The Intelligence Layer directly affects cost and execution quality:

- **Semantic Cache** avoids re-paying for identical or near-identical workloads
- **Prompt Optimizer** reduces model token consumption by producing tight, structured prompts
- **AI Router** ensures you pay only for the model tier appropriate to the task complexity (fast is cheaper; accurate costs more but is reserved for complex tasks)
- **Prompt Tutor** improves first-pass success rates, reducing failed executions
